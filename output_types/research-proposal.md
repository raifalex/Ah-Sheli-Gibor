# Output Type: Research Proposal

Research / grant proposal. For Israeli funding agencies (ISF, MAFAT, INCD, ISI), university committees, or international programs (EU Horizon, ERC, BSF, BIRD).

## When this output type is right

- **PhD research proposal** — Israeli university qualifying / advancement
- **Grant application** — ISF / MAFAT / INCD / EU Horizon
- **Postdoc proposal** — fellowship application
- **Industry-academia collaboration proposal**
- **Multi-PI consortium proposal**

## Length

5–30 pages depending on funder. TAU: 5–7 page synopsis. ISF: 15–25 typical. EU Horizon: 30–70.

## Structural template

### Cover page
- Title (Hebrew + English bilingual)
- PI + institution + affiliation
- Budget request + duration
- Keywords

### Abstract (~300 words)
Background + question + approach + significance.

### Background & significance (~2–4 pages)
Problem importance + prior work + gap.

### Specific aims (numbered, 3–5 aims)
Each aim: hypothesis + approach + expected outcome.

### Approach / methodology (~3–8 pages)
Detailed plan per aim with rigor / feasibility / alternatives.

### Preliminary results (~1–2 pages)
What's already been done to support feasibility.

### Timeline (~½ page)
Gantt-style year-by-year plan.

### Budget (~1 page)
Personnel, equipment, travel, consumables, overhead.

### References
Per funder format.

### CV / biosketch
PI track record + relevant publications.

## Hebrew-specific conventions

- **Israeli funder language conventions** — ISF formal Hebrew; MAFAT acronymized military-research style
- **Bilingual title + abstract**
- **Numbered aims** explicitly
- **Smikhut for compound research terms**
- **Past-tense for preliminary results, future-tense for aims**

## Persona pairings

| Proposal type | Best persona |
|---|---|
| Israeli academic (ISF / BSF) | **איתמר** (formal-classical) or **שירה** (literary precision) |
| MAFAT (defense research) | **איתמר** + defense-aerospace variation |
| EU Horizon (English primary, Hebrew section) | **שירה** for Hebrew portion |

## Validation gates

- [ ] Bilingual cover + abstract
- [ ] Numbered specific aims
- [ ] Feasibility evidence
- [ ] Timeline realistic
- [ ] Budget justified line-by-line
- [ ] Citations consistent
- [ ] Persona voice formal-academic
