# Output Type: Course Material

Educational content for Israeli academic institutions (Hebrew U, Technion, Bar-Ilan, TAU, IDC, Open University) or professional training programs. Covers syllabus, lesson plan, student handout, and assessment formats in one output type.

## When this output type is right

- **Academic course syllabus** — semester course at Israeli university
- **Lesson plan** — single session within a course
- **Student handout / reading guide** — supplementary materials
- **Professional training curriculum** — corporate or industry training
- **Online course module** — bootcamp / cohort-based course content
- **Assessment / rubric** — exam, problem set, project guidelines

## Six sub-formats

### 1. Syllabus

Full-semester academic course syllabus, Israeli university format.

**Sections:**
- Course title (Hebrew + English) + course number
- Instructor name, email, office hours
- Class meeting time + room
- Course description (~300 words) — what, why, for whom
- Learning objectives (4–8 specific outcomes)
- Prerequisites
- Weekly schedule (12–14 weeks; topic per week + readings)
- Assessments (% weights: exam / paper / participation / project)
- Required + recommended readings (per Hebrew U / Technion library format)
- Academic integrity statement
- Accommodations statement

### 2. Lesson plan

Single class session (50–90 minutes).

**Sections:**
- Lesson title + course context
- Learning objectives for this session (2–4)
- Materials needed
- **Opening** (5–10 min): hook, prior-knowledge check
- **Direct instruction** (20–30 min): new content presentation
- **Guided practice** (15–25 min): worked examples
- **Independent practice** (10–20 min): student work
- **Assessment** (5–10 min): exit ticket / quick check
- **Homework** (assigned for next session)

### 3. Student handout

Reading guide / explanation document.

**Sections:**
- Topic + course context
- Concept explanation (~500–1,500 words)
- 2–4 worked examples with full solutions
- Practice problems (10–20)
- Solutions key (separate page)
- Further reading recommendations

### 4. Assessment

Exam / problem set / project rubric.

**Sections:**
- Assessment title + course + week
- Instructions (time limit, allowed resources, format)
- Problems (point values explicit)
- Rubric for graded work (per-criterion scoring)
- Honor pledge

### 5. Course module (online / cohort-based)

Self-contained module, often online learning.

**Sections:**
- Module overview + estimated completion time
- Learning outcomes
- Lecture content (text + diagram references)
- Video / external resource links
- Activities + check-for-understanding quizzes
- Discussion prompts
- Capstone assignment

### 6. Reading guide

Pre-class reading assignment with focused questions.

**Sections:**
- Reading citation (per Israeli academic citation style)
- 3–5 focus questions for the reading
- 2–3 connection questions (relate to prior topic)
- Optional: 1–2 application questions

## Hebrew-specific conventions

- **Bilingual headers** for university courses (Hebrew first, English in parens)
- **Citation format**: Israeli academic style (often Chicago for Humanities, APA for Sciences)
- **Course numbers**: per institution (Hebrew U format: AAA-BBB-CCC)
- **Hebrew technical terminology** preferred where established (התפלגות / שגיאה / מסקנה / היפותזה)
- **Loanwords preserved** for tech terms (machine learning, neural network)
- **Quotation marks** Hebrew-style for Hebrew text
- **Numbers**: digital
- **Dates**: Israeli format

## Persona pairings

| Material type | Best persona |
|---|---|
| Academic syllabus | **איתמר** (formal, structured) or **שירה** (literary subjects) |
| Engineering / CS lecture material | **יואל** (founder-mode tech delivery) or **איתמר** (academic) |
| Intimate / mentor-led training | **נועה** (warm, supportive) |
| Sharp business / debate-driven training | **דנה** (panel-ready) |

## Sample syllabus excerpt (איתמר voice)

> # מבוא לבינה מלאכותית מודרנית
> ## Modern Artificial Intelligence — מס' קורס: 67510
>
> **מרצה:** ד"ר רותי לוי (rlevi@cs.huji.ac.il)
> **שעות קבלה:** רביעי 14:00–16:00, חדר 312
> **שעות הוראה:** ראשון + שלישי, 12:00–14:00, אולם רוס 70
>
> **תיאור הקורס:**
>
> הקורס מספק מבוא רחב לבינה מלאכותית, עם דגש מיוחד על מודלים גנרטיביים ומערכות agentic. במהלך הסמסטר נכסה את היסודות התיאורטיים (תורת הלמידה הסטטיסטית, רשתות עצביות, ארכיטקטורת Transformer), את הגישות העכשוויות (LLMs, RAG, fine-tuning, RLHF), ואת ההיבטים האפליקטיביים (deployment, validation, safety). מטרת הקורס: בוגרי הקורס יוכלו לבנות, להעריך ולפרוס מערכת AI מודרנית, ולנמק את בחירותיהם הארכיטקטוניות.
>
> **דרישות קדם:** מתמטיקה דיסקרטית · אלגוריתמים · הסתברות · אלגברה לינארית
>
> **משקלות הערכה:**
> - מטלות בית (5 מטלות): 30%
> - מבחן אמצע: 25%
> - פרויקט גמר (זוגות): 30%
> - השתתפות + נוכחות: 15%
>
> ...

## Validation gates

- [ ] Format-specific structure complete (per sub-format)
- [ ] Learning objectives measurable
- [ ] Assessment criteria explicit and fair
- [ ] Hebrew + English bilingual where required
- [ ] Citations in correct format
- [ ] Numbers digital
- [ ] Persona voice consistent
- [ ] Time-budget realistic (lessons; modules; readings)
