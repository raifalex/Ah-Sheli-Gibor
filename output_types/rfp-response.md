# Output Type: RFP Response (תשובה למכרז)

Proposal in response to an Israeli RFP (Request for Proposal) — known in Hebrew as a *michraz* (מכרז). Government RFPs, private enterprise RFPs, or framework tenders.

## When this output type is right

- **Government RFP response** — Israeli ministry / municipality / public sector michraz
- **Enterprise RFP** — large company's procurement process
- **Framework tender response** (מכרז מסגרת)
- **University procurement response**
- **NGO procurement response**

## Length

Highly variable; per RFP requirements. Government michrazim typically 50–200 pages.

## Structural template (mirrors RFP's required structure)

### Cover letter / declaration
- Per RFP-prescribed format
- Confirmation of compliance with mandatory conditions

### Compliance matrix
Section-by-section confirmation that proposal meets each RFP requirement.

### Executive summary
Why this proposer + this proposal best meets RFP needs.

### Company overview
- Legal name, structure, registration
- Years in business, key clients, financial stability
- Past performance on similar contracts

### Proposed solution
- Detailed technical/service proposal addressing each RFP requirement
- Architecture diagrams (if technical)
- Implementation plan
- Timeline

### Team & qualifications
- Key personnel + CVs
- Relevant certifications

### References
- Past clients on similar projects
- Letters of recommendation (per RFP requirement)

### Pricing
- Per RFP-prescribed pricing structure
- Often line-item per deliverable

### Terms & conditions
- Standard contract terms
- Proposed deviations from RFP standard terms

### Declarations (per Chok Chovat HaMichrazim)
- Per Israeli law required declarations
- Anti-corruption, non-collusion, etc.

### Appendices
- Detailed CVs
- Detailed pricing
- Technical detail
- Past project case studies

## Hebrew-specific conventions

- **Strict adherence to RFP structure** — deviation can cause disqualification
- **Hebrew language required** for Israeli government RFPs
- **Bilingual permitted** for some private RFPs
- **Formal addressing** (לכבוד / הואיל ו- / להלן)
- **Israeli legal references** per Chok Chovat HaMichrazim 5752-1992 + Takanot 5753-1993
- **Numbers + currency** precise with ₪
- **Israeli date format**
- **Declarations** per legal requirement — exact wording matters

## Persona pairings

| RFP type | Best persona |
|---|---|
| Government RFP | **שירה** (formal-classical) or **איתמר** (authoritative) |
| Enterprise RFP | **דנה** (sharp positioning) or **שירה** |
| Technical RFP | **איתמר** (depth) or **יואל** (engineering) |

## Validation gates

- [ ] Strict compliance with RFP-prescribed structure
- [ ] Compliance matrix complete (every requirement addressed)
- [ ] All required declarations present with exact statutory wording
- [ ] Pricing per RFP-prescribed format
- [ ] References meet RFP threshold (years, scale, similarity)
- [ ] Bid bond / performance bond per RFP
- [ ] Submission deadline / format respected
- [ ] Persona voice formal
- [ ] Hebrew grammar precise

## Related output types & skills

- For Israeli government RFP: pair with `israeli-tender-proposal-builder` skill
- For pricing strategy: separate financial analysis

## Pre-disqualification checklist

Israeli RFPs frequently disqualify on technical defects. Verify:
- [ ] All declarations present + signed
- [ ] All required attachments included
- [ ] Submission format exactly as required (page count, font, paper size)
- [ ] Bid bond filed
- [ ] Submission timing before deadline (Israeli holidays / Shabbat considered)
- [ ] Hebrew language requirements met
