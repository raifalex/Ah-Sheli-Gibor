# Output Type: Talking Cards

Talking cards are pre-prepared note cards (physical or digital) that a speaker holds, glances at, or has in front of them — usually for unscripted-but-prepared moments: panel debates, TV interviews, board meetings, podcast appearances, Q&A sessions, press conferences.

Unlike a teleprompter script (read verbatim) or a speech (delivered linearly), talking cards are **navigational anchors** — each card carries one idea the speaker can land in any order based on how the conversation unfolds.

## When this output type is right

- **Panel debate prep** — 5–8 cards covering likely arguments and rebuttals
- **TV interview** — opening soundbite, key stat, anticipated questions, closing line
- **Podcast appearance** — story prompts, signature points, comic relief beats
- **Board meeting** — your position on each agenda item, fallback compromises
- **Press conference** — opening statement plus 6–10 anticipated questions
- **Q&A after a keynote** — common questions and prepared answers
- **Difficult conversation** — manager preparing for a 1:1, founder preparing for a hard call

## Card structure (default — single card)

Each card has a fixed shape:

```
╭──────────────────────────────────────────╮
│ CARD #N — [topic label]                  │
│                                          │
│ HOOK (5–10 words):                       │
│ [one-line opener — the card's title-move]│
│                                          │
│ KEY POINT:                               │
│ [3–4 sentences max; the substantive idea] │
│                                          │
│ DATA ANCHOR:                             │
│ [one number, one fact, one quote]        │
│                                          │
│ LANDING LINE:                            │
│ [the soundbite that travels — must be    │
│  memorizable in ≤15 words]               │
│                                          │
│ FALLBACK / PIVOT:                        │
│ [what to say if the audience doesn't bite]│
╰──────────────────────────────────────────╯
```

## Default card set per scenario

### Panel debate (8 cards)

1. **Opening claim** (your headline position)
2. **Strongest evidence** (the data anchor that wins)
3. **Anticipated rebuttal A** (what the opponent will say + your response)
4. **Anticipated rebuttal B** (second-most-likely attack)
5. **Reframe** (when the conversation goes sideways — how you redirect)
6. **The triangulation move** (positioning yourself between extremes)
7. **The personal anchor** (a specific moment / story that grounds you)
8. **Closing question** (the question you want to leave the audience with)

### TV interview (6 cards)

1. **30-second opening** (if the host asks "tell us about it")
2. **Key stat** (the number that anchors your case)
3. **Anticipated tough question** (and your answer)
4. **The story** (the example that humanizes the argument)
5. **The compliment-and-pivot** (when host pushes back: agree partially, then redirect)
6. **The close** (the line you want viewers to remember tomorrow)

### Board meeting (5 cards — one per agenda item)

Per item:
1. **Your position** (yes/no/conditional, in one sentence)
2. **Why** (the reasoning, 2–3 sentences)
3. **Compromise position** (what you'd accept)
4. **Walk-away point** (what you wouldn't accept)
5. **Open question** (what you genuinely don't know and want input on)

## Hebrew-specific conventions

- **Lines are short.** A talking card is read at-a-glance. Never more than 8 lines per card.
- **No filler words.** Even more aggressive removal than for speeches.
- **The landing line is its own line.** Visually isolated on the card so the speaker can find it.
- **Approximation marker כ-** for any cited number.
- **Hyphen-prefix on English-script** (ב-X, ל-Y, ה-Z).
- **Cards are numbered** so the speaker can ask "card 4" if rehearsing with someone.

## Persona pairings

| Talking card scenario | Best persona |
|---|---|
| TV panel / political debate | **דנה** |
| Hostile press conference | **דנה** |
| Board meeting (founder-mode) | **יואל** |
| Board meeting (long-arc story) | **איתמר** |
| Podcast appearance (intimate) | **נועה** |
| Industry roast / awards MC | **גלעד** |
| Award acceptance Q&A | **שירה** or **נועה** depending on register |

## Validation gates (pre-output)

Before outputting talking cards, verify:

- [ ] Each card fits in 8 lines visible
- [ ] Landing line is ≤15 words and emotionally portable
- [ ] Data anchor is one specific number / one specific fact
- [ ] Fallback / pivot is explicit (named card # or named move)
- [ ] Cards are sequenced so the speaker can navigate dynamically
- [ ] No filler words
- [ ] Persona consistency across all cards
- [ ] Hebrew grammar checks clean
